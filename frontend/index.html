How Triage answers a question
01 Classify
A pattern-based classifier reads the question and decides which components it needs. No model call for this step.
02 Route
Numeric questions go to direct computation, content questions go to retrieval, comparisons go to chart aggregation.
03 Compute
Answers are produced deterministically — a real aggregation, a vector search, or a trained model. Never invented.
04 Synthesize
The model writes the final explanation grounded in exactly what was computed, so the text can't contradict the numbers.
